### 1. Об'єкт тестування
- **Назва:** Комп'ютерний ігровий монітор (Gaming Display 27")
- **Складові компоненти (5 частин):**
  1. Рідкокристалічна матриця з LED-підсвіткою
  2. Плата керування (скалер / motherboard)
  3. Блок живлення
  4. Корпус із кнопками керування / джойстиком
  5. Ергономічна підставка з регулюванням висоти та нахилу
